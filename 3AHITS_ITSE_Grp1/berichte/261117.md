## Übung 3.5 (Base64 kodieren)

Hex in Binär, in 6-Bit-Gruppen teilen und mit der Base64-Tabelle umwandeln. 

### (1) `4F 6B 21`

`01001111 01101011 00100001` -> `010011 110110 101100 100001` -> 19 54 44 33

Ergebnis:
```
T2sh
```

### (2) `48 61 6C 6C 6F`

`01001000 01100001 01101100 01101100 01101111` -> `010010 000110 000101 101100 011011 000110 1111`+`00` -> 18 6 5 44 27 6 60

Letzte Gruppe hatte nur 4 Bits, daher `00` aufgefüllt und ein `=`.

Ergebnis: 
```
SGFsbG8=
```

## Übung 3.7 (SHA256 mit Shell-Tools)

**Hashwert als Hex:**

```bash
openssl dgst -sha256 goethe.txt
```

```
SHA2-256(goethe.txt)= a911a35ff92bcd4250c063a0547dae3f1ba2b839eaf12b64c955cf3ff7e570e0
```

### Nur den Hex-String

**Variante 1 (`cut`):**

```bash
openssl dgst -sha256 goethe.txt | cut -d' ' -f2
```

**Variante 2 (`-binary` und `xxd`):**

```bash
openssl dgst -sha256 -binary goethe.txt | xxd -p -c 64
```

Beide Ausgaben:

```
a911a35ff92bcd4250c063a0547dae3f1ba2b839eaf12b64c955cf3ff7e570e0
```

### Base64

**Variante 1 (`openssl`):**

```bash
openssl dgst -sha256 -binary goethe.txt | openssl base64
```

**Variante 2 (`base64`):**

```bash
openssl dgst -sha256 -binary goethe.txt | base64
```

Beide Ausgaben:

```
qRGjX/krzUJQwGOgVH2uPxuiuDnq8StkyVXPP/flcOA=
```

### Länge mit `wc -c`

| Darstellung | Bytes | Befehl |
|---|---|---|
| binär | 32 | `openssl dgst -sha256 -binary goethe.txt \| wc -c` |
| hex | 65 (64 + Zeilenende) | `openssl dgst -sha256 goethe.txt \| cut -d' ' -f2 \| wc -c` |
| base64 | 45 (44 + Zeilenende) | `openssl dgst -sha256 -binary goethe.txt \| base64 \| wc -c` |

Der Hash hat 256 Bit = 32 Bytes. Hex braucht 2 Zeichen pro Byte (64), Base64 braucht 4 Zeichen pro 3 Bytes (44 inklusive `=`). Das Zeilenende zählt `wc` jeweils mit.
